# Phase 2 output template

Place the separately supplied `CAPEX_FLOW_Proposed_Finance_Register_Template.xlsx` in this directory for local runs.

The Excel binary template is delivered as a downloadable artifact in the project hand-off. It is deliberately not included in this text-file commit because the GitHub connector's contents write action accepts UTF-8 text only.

Do not replace this generic template with an employer workbook unless IT and Finance authorize its use and storage.
